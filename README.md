# go-react-template

[Copier](https://copier.readthedocs.io/) template: Go (huma, pgx, goose) server + React (TanStack Router,
Tailwind, shadcn) web app, managed with mise and lefthook.

## Use

```sh
copier copy gh:iskolar-web3/go-react-template my-app
```

Update an existing project to the latest template:

```sh
cd my-app && copier update
```

Template files live in [`template/`](template/); questions in [`copier.yml`](copier.yml).
